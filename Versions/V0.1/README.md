# Travel Companion Alpha v0.2 – Budapest

## Fő változások
- Valós OpenStreetMap / Leaflet térkép
- 24 budapesti teszthely
- 3 napos laza tesztútiterv
- Naponként eltérő útvonalszín
- Navigációs gomb minden helyhez
- Aktuális hely meghatározása
- POI-koppintáskor csak kis Peek panel
- Felhúzással Half és Full állapot
- Lefelé húzáskor mindig Mini alapállapot
- Térképre koppintva panel visszacsukása
- Lágyabb, rugósabb panelátmenet

## Indítás
A mappát érdemes GitHub Pages-en vagy egyszerű helyi webszerveren futtatni, mert a Leaflet és az OpenStreetMap térképcsempék internetkapcsolatot igényelnek.

Közvetlenül az `index.html` is megnyitható, de iPhone-on a helymeghatározás és PWA-funkciók HTTPS alatt működnek a legjobban.
